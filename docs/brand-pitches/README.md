# Brand Pitch Documentation

This folder keeps reusable guidance and project notes for customer-specific pitch pages.

```text
docs/brand-pitches/
  playbook.md
  revolve-video-generation-workflow.md
  plans/
  specs/
```

- `playbook.md` is the reusable standard for customer-facing brand pitch pages.
- `revolve-video-generation-workflow.md` records the verified generation and QA workflow behind the REVOLVE V4 demo.
- `plans/` holds execution plans for specific pitch projects.
- `specs/` holds design and QA specs for pitch pages and review tools.

Deployable customer pages live separately under `deploy/brand-pitches/<brand>/<pitch-name>/`.
